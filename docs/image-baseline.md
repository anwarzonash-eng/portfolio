## Not measured, and why

No runtime numbers are in this baseline. There is no `.env.local`, no API key and no
staging environment, so the app cannot be booted against real data. The following were
therefore **not** captured and must be measured later against a real environment:

- Per-route image bytes (HAR)
- Lighthouse LCP / Total Byte Weight / "properly size images" / "next-gen formats"
- Which element is LCP per route
- Cold vs warm `/_next/image` cache behaviour
- PDF capture wall-clock time per print route, and output PDF size
- Total API-supplied image bytes per tenant

Any later claim of a page-speed improvement must come from those numbers, not from the
file sizes in this document. File size and page speed are different scoreboards.
